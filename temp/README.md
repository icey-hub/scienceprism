# SciencePrism 前端设计 Demo（Apple Design）

> 这是一个**只读项目前端之后重做的设计 Demo**：零依赖、零构建、不碰仓库任何既有文件。
> 数据是本地夹具，不联网、不调用后端、不写项目。

## 怎么打开

```bash
# 1) 直接双击（最省事，file:// 已验证可用）
open temp/index.html

# 2) 起一个静态服务（本机当前已在跑：http://127.0.0.1:8912/）
cd temp && python3 -m http.server 8912 --bind 127.0.0.1
```

**想看动效就直接进 `#/motion`（左栏「特效巡演」）**：十个招牌动效进页面就自动播一遍。

## 招牌特效（这些是「看得见的 Apple」）

| 特效 | 在哪看 | 兑现的规则 |
| --- | --- | --- |
| **英雄过渡** | `#/` 点任意文稿卡片 | 匹配几何：卡片「长成」目标标题区，几何/圆角/内容淡入由同一个弹簧驱动，中途抓住也不跳 |
| **照片缩放** | `#/editor` 点右侧 PDF 页面 | 从小图长成一块大面板，关闭沿原路缩回；可向下拖拽甩掉 |
| **液态玻璃** | 任意面板 / 卡片 / 工具条 | 高光跟着指针走（镜面反射）+ 材料到位时被光扫过 + 指针位置决定 3D 视差 |
| **动态岛** | `#/editor` 点「编译」 | 胶囊按内容用弹簧长宽，状态色跟着语义过渡（编译中 → 成功 → 待命） |
| **橡皮筋滚动** | 任意长页面滚到底继续滚 | 到边界跟手但越来越沉，松手带速度弹回，不是硬停 |
| **弹簧列表重排** | `#/motion` 第 10 个 / 控制室资料页 | 拖起一行它 1:1 跟手，其余行用弹簧让位；松手按投影决定插到哪一格 |
| **挤压与拉伸** | `#/motion` 第 03 / 06 个 | 抽屉拖动时沿运动方向拉长；落地那一帧压扁再弹回 |
| **速度即拉伸** | `#/motion` 第 07 个 | 高速时沿运动方向拉长、垂直方向压扁 |
| **中途改主意** | `#/motion` 第 02 个 | 重定向时从「当前屏幕上的值」出发并带走原速度，不先飞完再回头 |
| **环境光斑** | 整个应用背景 | 极慢的棱镜折射光斑，让静止画面也是活的（降低动效下完全停住） |

底层是一个自写的弹簧求解器（`scripts/core.js`）：`damping` + `response`，半隐式欧拉 + 固定子步长，
重定向时默认沿用当前速度。**所有手势驱动的动画都没有 CSS transition**，所以可以随时打断、反向。

Apple 的动量投影公式（不是教科书的 `v²/2a`）：

```js
project(v) = (v / 1000) * d / (1 - d)      // d = 0.998 ≈ 系统滚动手感
```

`#/motion` 第 04 个和 `#/design` 都有可直接拖的投影计算器，实时显示释放速度、投影落点、吸附目标。

## 如果你觉得「没有特效」——先看这一条

**如果你的 macOS 开了「设置 → 辅助功能 → 显示 → 减弱动态效果」，这套界面会按规范把所有位移降级成交叉淡入。**
那是刻意行为，不是坏了 —— 但结果就是「看起来什么动效都没有」。

Demo 启动时会检测并弹出诊断条：

> 检测到系统开启了「减弱动态效果」… 点「临时预览完整动效」可以本次会话覆盖。

三套系统偏好都真的接上了，可以在 `#/design` 或控制室「设置」页当场验证：

| 系统偏好 | 行为 |
| --- | --- |
| `prefers-reduced-motion: reduce` | 位移/缩放直接到位，只保留淡入；弹簧不过冲；环境光斑停住 |
| `prefers-reduced-transparency: reduce` | 材料变实心并去掉所有 `backdrop-filter` |
| `prefers-contrast: more` | 实心底 + 明确边框 + 更深的文字 |

`#/motion` 还提供 **慢放 0.25×**（全局时间缩放，把每帧 dt 乘 0.25）：弹簧参数不变、手感不变，只是走得慢
—— Apple 建议这样逐帧回看动效。

## 设计决策（以及它对应 Apple 的哪条）

### 1. 材料与层级 —— 用材料分区域，不用 1px 分割线

- 左栏 `blur(28px)` 最厚（结构性区域），工具条 `24px`，面板 `18px`，抽屉 `40px` 最厚（浮在最上）。
- **越大的面越厚**：模糊更强、阴影更深。`#/design` 的材料区把这四档并排放在同一张花哨背景上，可以直接看出差异。
- 半透明材料上**不放第二层半透明材料**；材料上的文字抬字重、微加字距，而不是调成灰色。

### 2. 排版 —— 字距随字号变化，行高反向跟随

- 系统字体栈，Display `-0.024em`，Caption `+0.006em`，Overline `+0.09em`；三者成组定义为 token。
- 间距用 `rem`，跟随用户字号设置。

### 3. 弹簧 —— 参数是 damping + response，不是时长

出厂默认 `damping 1.0 / response 0.28–0.4`；只有手势本身带了动量（甩、拖拽释放）才降到 `0.8`。
分栏、抽屉、审批行、阶段切换、页签指示块用的都是同一套原语。

### 4. 手势 —— 1:1 跟手、动量投影、越界橡皮筋

| 位置 | 兑现的规则 |
| --- | --- |
| 编辑器两根分栏条 | 尊重抓取偏移、1:1 跟手、越界橡皮筋、双击复位、方向键可达 |
| 审批行左右滑 | 释放速度 → 投影 → 吸附到投影点 → 把速度交给弹簧 |
| 研究阶段「人工确认」 | 按住 0.9 秒才提交，提前松手回弹；视觉 + 触觉 + 声音同帧 |
| 底部抽屉 | 抓手可拖、可中途反向、松手按投影决定关闭还是回弹、拖动时轻微拉伸 |
| 页签分段控件 | 按住横向拖动时指示块跟着指针走，落定时有轻微过冲 |
| PDF 页面 | 点开是照片缩放，拖动可甩掉，关闭沿原路缩回 |

### 5. 空间一致性与退出路径

- 浮层从触发它的那个角长出来；关闭走原路。
- 英雄过渡只在**有空间连续性**的跳转上用（卡片 → 目标）；普通导航只做 260ms 交叉淡入 + 6px 上浮。
- 研究阶段切换有方向性：往后从右进，往回从左进。

### 6. 安全与自主 —— 让确认有成本

- AI 提议的 Patch、受控实验运行、阶段推进，全部要**按住**才提交。
- 只有不可逆动作（跳过论文复现）才给一次明确的确认弹层；其余靠可撤销 + 状态可见，不堆弹窗。

### 过程中修掉的真实缺陷

1. `ui.setRing(null, …)` 抛 TypeError → 研究工作区与编辑器的 `mount` **整体中断**（页面看着渲染了，其实后半段没接上）。
2. `.btn.ghost` 覆盖了 `.btn.primary` 的底色但没覆盖前景色 → 切换态按钮变成**白字白底，肉眼看不见**。
   现在用独立的 `.btn.is-on`，并把它放在 `.ghost` 之后。
3. 材料演示把花纹画在了玻璃**上面**，导致四档材料看不出差别；已改为花纹在下、玻璃在上。

## 非目标 / 已知取舍

- 不接后端：没有真实 LaTeX 编译、没有真实模型调用，`#/project/p-02…p-06` 复用 p-01 的数据。
- 只有中文；没有做 i18n 切换（项目里是 i18next 双语）。
- 桌面优先；窄窗只保证不碎（左栏收成图标条、PDF 栏隐藏）。
- 没有用 React / 组件库：Demo 是 classic script，为了让「双击就能看」成立。
- 环境光斑是慢速循环，Apple 通常不建议；这里作为 Demo 的视觉演示保留，并在降低动效下完全停用。
- 控制室页签是本地状态，没有同步进 URL（只有初始页签从 URL 读）。
