# CCF-A Paper Storyline

Use this for a substantial writing handoff or full-paper plan. Preserve the approved method, evidence IDs, measured values, and citation keys.

1. Write the central claim as **problem → insight → mechanism → evidence → scope**. Each arrow must be supported by the project record; flag a missing link.
2. Allocate sections by argument function: introduction states the question and contribution; related work positions the mechanism; method defines what was actually built; experiments test the claim; discussion distinguishes observations from interpretation. Give a page or word budget only when a venue and format are known.
3. Map each headline claim to confirmed evidence IDs and the figure or table that would let a reader inspect it. Keep planned or pending experiments in the work plan, not the results narrative.
4. Check that title, abstract, introduction, result captions, and conclusion express the same bounded contribution. Remove repetition that does not add evidence.
5. For a named venue, consult its current official author instructions before declaring compliance. Mark an unknown page limit or template as unverified.

Return the writing stage's JSON contract. Record unsupported claims and unresolved venue or evidence requirements explicitly; never fill missing results with plausible numbers.
