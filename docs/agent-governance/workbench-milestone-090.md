# 里程碑 090：统一助手执行与版本绑定应用

> 2026-10-03 完成。首个可用里程碑：普通助手任务使用持久 Run 生命周期，支持上下文、停止、恢复与重试；修改提案关联文稿版本，经统一应用接口审阅，拒绝覆盖用户的新修改。

## 目标与范围

在现有编辑器中完成 T00–T05 检查点 B：

1. 普通问答与修改共用一个可查询、可取消、可重试的 Run 生命周期，取消会到达执行器。
2. 任务输入记录参与任务的文稿版本与必要上下文，前端不再发送重复的整项目文本。
3. 提案接受只能走统一应用接口；服务端预检版本冲突并保留用户的新内容；重复应用幂等，多文件失败有可恢复记录。

非目标：不迁移 Skill 目录、不收缩默认导航、不完成编译/引用闭环，不删除研究阶段或多 Agent 数据；这些属于后续 T06-T12。

## 实现摘要

### 后端

- **统一助手服务** (`assistantService.js`)：编辑器任务创建与启动复用 `createHarnessRun` 和 `startHarnessRun`；验证 requestId、指纹、文稿版本，串行化同项目启动，检查重复请求和活动任务冲突。
- **Context Pack 历史** (`harnessRuntime/contextPackager.js`)：规范化并存储最后 8 条对话历史，每条最多 16,000 字节；历史参与预算，manifest 包含角色、长度和 SHA-256，不重复完整文本。
- **生命周期恢复** (`harnessRuntime/index.js`)：取消与暂停的 fallback catch 分别返回 `cancelled` / `paused` 而非 `failed`；编辑器 Run 超过 100 条仍保留完整记录；孤立运行中 Run 恢复为可重试的 `HARNESS_INTERRUPTED`。
- **版本绑定应用** (`harnessRuntime/patchApplication.js`)：全量预检所选文件的基准版本、路径约束和协作状态；事务写入中故障记录原始内容与操作日志，自动恢复或留待人工；重复应用幂等，不重复写入。
- **文件保存同步** (`routes/projects.js`、`collab/docStore.js`)：保存预检期望版本与协作草稿一致性，拒绝不匹配；应用事务与保存共享项目锁；协作 flush 同样拒绝更新的磁盘版本。

### 前端

- **持久助手 Run** (`editor/useAssistantRun.ts`)：轮询编辑器来源 Run 列表，保留完整历史；启动前准备文稿版本，保存失败中止创建；明确停止调用后端取消；追问使用服务端持久历史。
- **草稿版本管理** (`editor/useDocumentDrafts.ts`)：按项目保留活动与非活动草稿、已保存内容和版本；串行化保存、版本获取与应用工作；保存使用期望版本，versions 拒绝保存中或磁盘不匹配。
- **修改审阅** (`editor/useChangeReview.ts`)：从 Run 提案与决定派生待审阅项；按 Run 分组路径；接受使用 decision 终端后统一 apply；拒绝只记录决定。
- **应用互斥** (`EditorPage.tsx`)：`applyReviewedChanges` 预检未保存草稿，应用完成后刷新受影响文件，保留运行期间的新内容；协作活动文件需连接、flush 和内容匹配；编译前保存并抛错。

## 关键设计决定

1. **复用 Harness 现有能力**：编辑器任务不另建生命周期，直接用 Run、事件、decision、apply 接口。
2. **Context Pack 存储历史**：历史参与预算，manifest 只投影元数据，不在模型请求中重复发送完整文本。
3. **版本绑定应用**：提案关联基准版本，应用前全量预检，事务写入记录原始内容，失败自动恢复或留可恢复日志。
4. **草稿与应用互斥**：应用前拒绝未保存草稿；协作活动文件需 flush 且内容匹配；应用完成后只刷新实际变化文件。
5. **串行启动与冲突检测**：同项目编辑器任务串行化，活动任务阻塞新请求；重复 requestId 返回已有 Run，指纹变化报告冲突。

## 遗留与限制

1. **浏览器验收未执行**：自动化测试证明机制正确，手工流程待补全；实际模型输出质量未评估。
2. **前端不显示工具事件**：Run 已记录工具调用，界面只显示终态与回复；详细事件在折叠详情中。
3. **Context Pack 内容不可见**：用户看不到实际打包的文件与历史范围；manifest 在 Run 详情但无专门展示。
4. **Skill 目录未迁移**：编辑器任务暂不支持选择 Skill；研究阶段绑定继续有效。
5. **默认导航未收缩**：六个同级入口保留；工作台布局属于后续 T06–T08。
6. **编译与引用未闭环**：编译错误定位和引用核对属于 T09–T10。
7. **旧路径未删除**：编辑器仍有 Chat/Agent 两套数组、direct/tools 模式、旧 `applyPending` 分支；清理属于 T11。
