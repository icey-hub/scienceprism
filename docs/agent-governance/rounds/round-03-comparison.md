## 4. 本轮最有价值的产出

### ① 绘图：从"画不出来"到"能画细胞结构图"

基准按用户的纠正设为**复杂矢量插画**（不是线段方框）。产物见 `assets/diagrams/cell-structure.png`：细胞膜磷脂双分子层、核膜/核孔/核仁/染色质、3 个带嵴线粒体、粗面内质网+核糖体、高尔基体、溶酶体、液泡、中心体、游离核糖体、**12 个中文标注**。

**主方案 = 手写 SVG**，理由是它在约束下唯一同时满足：能画任意插画、零安装、离线、中文直出、可 diff、**不往工作区外写缓存**。Mermaid / D2 / Graphviz / PlantUML 在原理上画不出这类图；MCP 路线因"配置须写 `~/.dsh/settings.yaml`（越界）"而关闭。

### ② C-07：把"文档撒谎"变成真的

C-07 声称"原项目只经**显式 Patch 应用**变更"，而**全仓库没有应用 Patch 的接口**——这半句一直"成立"只是因为没被实现。本轮实现了它，并刻意做窄：必须人工已接受、写入时按**当前**策略复核、同一 Patch 绝不应用两次。

### ③ 死代码与死配置：先取证，再动手

- **一半 skill 绑定指向永不执行阶段**（`direction`/`selection`/`replication`/`experiment`）→ 删除，并把"绑定必须可达"做成不变量。
- **9 个零引用导出** → 逐个核实后删 7 留 2，留下的 2 个（Source Adapter Seam、Harness Adapter 注册）都有**文档承诺**作为依据，并加了"为什么保留"的注释。
