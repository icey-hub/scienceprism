## 4. 用这个项目做 AI 研究

**方向**：人工智能 —— GSM8K 上的思维链消融。

| 项 | 内容 |
| --- | --- |
| **数据集** | GSM8K 测试集（Cobbe et al. 2021），自下载 1319 题，确定性抽样 200 题 |
| **参考论文** | 全部用 **arXiv API 核实**（非记忆）：Wei 2201.11903、Wang 2203.11171、Kojima 2205.11916、DeepSeek-R1 2501.12948、GSM8K 2110.14168 |
| **实验** | 3 条件 × 200 题 = **600 次真实生成**，temperature 0，严格串行 |

### 结果（真实数字）

| 发现 | 数据 |
| --- | --- |
| **CoT 增益恰好为 0** | 0.955 vs 0.955；逐题配对不一致仅 **2/200** |
| 强制答案格式**略微有害** | −0.01，且慢 28% |
| **96% 结果与提示条件无关** | 188 全对 / 8 全错 / 仅 4 题变化 |
| **隐藏推理比可见答案更不准** | 25 次"答案对、推理错" vs **1 次**反向 |
| **exact-match 判分低估 1.0 个百分点** | 6/600 数值相等而字符串不同（`12` vs `12.00`） |

**创新点**：对推理模型，提示几乎不改变结果；**主要误差来自题目难度与判分规则**，不是提示。

## 5. 🎯 真正使用暴露的产品缺陷

**`handoff-writing` 的舞台输入不含证据账本**：

```js
{ direction, papers: selectedPapers, ideas, method, experiment }   // 缺 evidenceLedger
```

后果：**项目能把实验结果记为 Evidence，但写作阶段看不到它**——论文永远无法引用自己跑出的实验结果。模型说"experiment-run 证据缺失"是**准确的**。

**已修**（账本进输入，摘要截断以适配 Context Pack）。修复后模型**看得到**了，并正确指出该条目是 `pending`，拒绝以其支撑论断——**理由从错误的"不存在"变成正确的"存在但未验证"**。

**这也揭露出自主科研的一个真实张力：agent 能跑实验，但不能认证自己的结果**（章节最终标题是 "Results (pending verification)"）。

## 7. 新增的三条图门禁

| 断言 | 拦什么 |
| --- | --- |
| **可复现** | 从数据重生成必须逐字节一致 → 图不能被手改 |
| **数据现算** | **扰动数据后图必须变化** → 数字真的来自数据 |
| **布局** | 6 张图全过检查 |

**② 最容易漏**：只比对真实数据**证明不了**来源——写死的 `0.955` 在一致数据下照样通过。

**两次破坏实验验证**：
- 注入重叠标签 → **挂 2 项**（布局 + 可复现，报出 3020px² 重叠）
- 硬编码数字 → **只挂"数据现算"那一项**
