# 🚨 OpenPrism 重构计划总结

**日期**: 2026-10-04  
**状态**: 等待用户确认方向  

## 📋 已完成的诊断工作

我对项目进行了全面诊断，主要发现：

### 核心问题
1. **代码规模失控** — `EditorPage.tsx` 4899 行，后端 91 个服务文件
2. **架构过度设计** — 8 阶段研究流程、17 条约束、8 个角色系统
3. **功能分散** — 6 个导航入口，用户找不到基本功能
4. **技术债严重** — 两套对话系统、两套修改应用、伪装的打字动画

### 与 Codex+Skill 对比
- **上手成本**: 高 10 倍（需理解研究阶段、角色、约束）
- **功能发现**: 需要 3-5 次点击
- **AI 体验**: 伪装打字 vs 真实流式
- **可靠性**: 停止失败、冲突未处理

## 🎯 推荐方案：混合式重构

**第 1 周**（激进式删除）:
- 删除研究阶段 UI（8 个文件）
- 删除角色系统
- 删除约束注册表
- 删除多 Agent 委派
- 删除绘图/OCR/Transfer 面板

**第 2-3 周**（渐进式打磨）:
- 统一 AI 助手入口（合并 Chat/Agent）
- 真实流式输出 + 可靠停止
- 统一修改应用 + 版本冲突检测
- 编译修复闭环
- 引用核对闭环

**第 4 周**（Skill 生态）:
- 目录扫描 + 热加载
- 5 个常用 Skill
- 社区贡献文档
